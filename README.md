# MuaazMed

Wits GEMP1 learning site.

- `index.html`: lightweight entry page. This is the GitHub Pages home page.
- `eye.html`: end-of-year integrated assessment (EYE), clinical clusters and practice papers.
- `legacy.html`: preserved previous complete Renal/GIT/Past Papers/EYE site.
- `msk.html`: existing musculoskeletal module.
- `CNAME`: custom domain configuration.

All pages are static and deploy through GitHub Pages. Course progress uses browser local storage. The EYE question bank includes student-derived material and is not an official Wits examination paper.

**Note:** Friends' PDF notes are not redistributed in this public repository. The EYE notes area contains extracted summaries and the site links to Wits Ulwazi/Google Drive for permitted sources.
